# دليل تشغيل النظام في الصيدلية

هذا الدليل لتشغيل النظام فعلياً (على جهاز الصيدلية أو سيرفر)، وليس للتطوير.

## 1) بعد كل تحديث للملفات

من مجلد المشروع (`C:\wamp64\www\erp-system`) في سطر الأوامر:

```bat
php artisan migrate
php artisan db:seed --class=RolesAndPermissionsSeeder
php artisan optimize:clear
```

- `migrate` ينشئ الجداول الجديدة (المرتجعات، الورديات، الجرد، دفعات الموردين، المستودعات).
- الـ seeder يضيف الصلاحيات الجديدة. **الأدوار غير المدير لا تأخذها تلقائياً**: افتح «الأدوار والصلاحيات» وفعّلها لمن يحتاجها.

## 2) عدة صيدليات وفروع (مهم)

النظام مقسوم لثلاث مستويات، وكل مستوى يرى بياناته فقط تلقائياً في كل الشاشات والتقارير:

| المستخدم | الدور | الصيدلية | الفرع | يرى |
|---|---|---|---|---|
| أنت | `Admin` | (أي) | فارغ | كل الصيدليات |
| صاحب الصيدلية | `صاحب صيدلية` | صيدليته | فارغ (كل الفروع) | كل فروع صيدليته |
| مدير الفرع | `مدير فرع` | صيدليته | فرعه | فرعه فقط |
| الكاشير | `كاشير` | صيدليته | فرعه | نقطة البيع وفواتير فرعه |

- **الأصناف والأسعار** لكل صيدلية لحالها (الصيدليات لا ترى أصناف بعض).
- **المخزون لكل فرع**: البيع ينقص من رصيد الفرع فقط، والنقل بين الفروع من «نقل المخزون».
- **العملاء وديونهم لكل فرع**.
- **الحسابات والقيود** لكل صيدلية دليل حسابات خاص بها.
- طرق الدفع والأدوار مشتركة ويديرها مدير النظام فقط.

### إضافة صيدلية جديدة (من حسابك)
1. «الصيدلية والفروع ← الصيدليات» ← إضافة صيدلية. يُنشأ معها «الفرع الرئيسي» ومستودعه تلقائياً.
2. «المستخدمون» ← مستخدم جديد: اختر الصيدلية، واترك الفرع «كل الفروع»، والدور `صاحب صيدلية`.
3. أعطِ صاحب الصيدلية اسم المستخدم وكلمة المرور.

### صاحب الصيدلية يجهّز صيدليته
1. «الفروع»: يضيف فروعه (كل فرع يأخذ مستودعاً تلقائياً) والخزائن لكل فرع.
2. «المستخدمون»: يضيف لكل فرع مدير فرع وكاشيرية (يختار الفرع والدور).
3. «المنتجات» و«توريد بضاعة»: يدخل الأصناف، والتوريد يدخل مخزون الفرع.

### إيقاف صيدلية أو فرع
من شاشة الصيدليات/الفروع اجعل الحالة «غير نشط»: كل مستخدميها يخرجون فوراً ولا يستطيعون الدخول.

## 3) إعدادات ملف `.env` للتشغيل الفعلي

| الإعداد | القيمة | السبب |
|---|---|---|
| `APP_ENV` | `production` | |
| `APP_DEBUG` | `false` | **مهم جداً**: بدونها تظهر تفاصيل الأخطاء وكلمات سر قاعدة البيانات لأي زائر |
| `APP_URL` | رابط الموقع الفعلي | |
| `APP_TIMEZONE` | `Asia/Hebron` | حتى تُحسب «مبيعات اليوم» والورديات والنسخ الليلية بالتوقيت المحلي |
| `SESSION_SECURE_COOKIE` | `true` | فقط إذا كان الموقع يعمل عبر HTTPS |
| `ALLOW_REGISTRATION` | `false` | المستخدمون يُضافون من شاشة المستخدمين فقط |
| `DB_PASSWORD` | كلمة سر قوية | لا تترك مستخدم `root` بدون كلمة سر على جهاز متصل بالشبكة |

> تغيير `APP_TIMEZONE` على قاعدة فيها بيانات قديمة يجعل أوقات السجلات القديمة تظهر مزاحة بساعتين (أو ثلاث في الصيف). البيانات نفسها لا تتغير.

بعد تعديل `.env`:

```bat
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

(وعند أي تعديل لاحق على `.env` أعد `php artisan config:cache`.)

## 4) المهام المجدولة (التنبيهات اليومية والنسخ الاحتياطي)

النظام يشغّل تلقائياً:
- **07:30** ملخص يومي بالنواقص والدفعات المنتهية والقريبة من الانتهاء يصل كإشعار لمن يملك صلاحية الصيدلية.
- **23:30** نسخة احتياطية كاملة لقاعدة البيانات في `storage/app/backups` (يُحتفظ بآخر 14 نسخة).

هذا يحتاج أن يعمل `php artisan schedule:run` **كل دقيقة**. على Windows:

1. افتح **Task Scheduler** (جدولة المهام) ← Create Task.
2. تبويب General: الاسم `ERP Scheduler`، واختر «Run whether user is logged on or not».
3. تبويب Triggers ← New: Daily، ثم «Repeat task every: 1 minute» لمدة «Indefinitely».
4. تبويب Actions ← New:
   - Program: مسار php، مثلاً `C:\wamp64\bin\php\php8.2.13\php.exe` (حسب نسختك)
   - Arguments: `artisan schedule:run`
   - Start in: `C:\wamp64\www\erp-system`
5. احفظ. للتأكد: شغّل `php artisan schedule:list`.

يمكن أيضاً التشغيل اليدوي في أي وقت:

```bat
php artisan alerts:daily
php artisan backup:run
```

أو من صفحة «إدارة النظام ← النسخ الاحتياطية» زر «نسخة الآن».

**احفظ نسخة خارج الجهاز** مرة في الأسبوع على الأقل (فلاشة أو Google Drive). النسخة على نفس الجهاز لا تحمي من تلف القرص أو السرقة.

## 5) الاسترجاع من نسخة احتياطية

1. خذ نسخة من الوضع الحالي أولاً.
2. فك ضغط ملف `erp-....sql.gz` ببرنامج 7-Zip.
3. من phpMyAdmin افتح قاعدة `erp_system` ← استيراد ← ارفع ملف `.sql`.

## 6) الاختبارات

الاختبارات تعمل على قاعدة منفصلة حتى لا تمسح بياناتك:

1. أنشئ قاعدة فارغة اسمها `erp_system_testing` من phpMyAdmin.
2. شغّل `php artisan test`.

## 7) طريقة العمل اليومية المقترحة

1. الكاشير يفتح **وردية** على خزينته أول الدوام (المبيعات النقدية تُسجل عليها تلقائياً).
2. البيع من **نقطة البيع**؛ الإيصال الحراري من صفحة الفاتورة.
3. أي إرجاع من صفحة الفاتورة ← **مرتجع** (لا تحذف الفاتورة).
4. آخر الدوام: يعدّ الصندوق ويغلق الوردية؛ النظام يسجل الزيادة أو العجز.
5. المدير يراجع **التقارير ← الأرباح** و**مبيعات الموظفين** أسبوعياً، و**الأصناف الراكدة** شهرياً.
6. **جرد** كل شهر أو كل تصنيف بالتناوب.
